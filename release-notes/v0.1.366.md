# thread0 0.1.366 (Windows) / 0.1.367 (macOS)

Windows 0.1.366 and macOS 0.1.367 contain the same app; the macOS build only carries extra test fixes.

This release lets you comment on AI answers and text results, masks what the AI reads in security mode for Claude, GPT and Gemini, and stops GPT accounts from signing each other out. Updates now install quietly when you quit or step away, guests can see whether their host is on, and organization PCs behave correctly when a member is removed, a PC is released or the organization is deleted.

## Changes

### Comments on answers and files
- Select text in an AI answer (or tap a paragraph on a phone) to add a comment. Collect as many as you like and send them with your message as one review. Sent reviews show as a card.
- Markdown, text and code results open inside the app on the PC and the phone. **Edit** lets you comment on lines and send them to the session that made the file.
- An answer that is still being written cannot be commented on until it finishes.

### Security mode
- In security turns, what the AI reads with its tools — files it opens, command output, search results — is masked before it reaches the model, and placeholders are restored when it writes. This now works in Claude, GPT and Gemini sessions.
- The security default and its check items act as one switch: turning on a check turns on security mode, and turning on security mode turns on personal-data protection.
- Secrets in code and configuration (private keys, tokens, cloud keys, passwords in connection strings) are masked.
- Japanese and Chinese text is not yet detected.

### GPT
- Sessions of the same GPT account share one connection, so two sessions refreshing at once no longer sign the account out.
- The first command on Windows no longer waits about 80 seconds: thread0 prepares the sandbox in the background after you sign in.
- Korean, Japanese and Chinese files read and written by PowerShell commands (GPT and Gemini) are no longer garbled.

### Accounts and sign-in
- If a Claude or GPT login is shared with another folder or with this PC's own terminal, the account card warns you and offers a separate thread0 sign-in, because shared logins sign each other out.
- A message sent while sign-in is still in progress waits and is sent once you finish signing in.
- A conversation of a signed-out account opens normally and offers to sign in again or switch accounts inside the session.
- Gemini: an expired sign-in in the middle of a session recovers on its own once.
- On the phone, requests no longer fail when the browser cannot provide its security check token.

### Updates
- A downloaded update installs when you quit thread0, and on Windows while nothing is running and you are away for 10 minutes. Phones and guests see "updating" instead of a lost connection. You can turn this off in **Settings → Updates**; organizations can lock it.

### Projects
- Create a project with the name you want, rename it, move it to the trash and search projects — on the PC and the phone.

### Home
- Recent activity follows the order of your session list. When nothing is running, it shows the top four sessions.

### Guests and hosts
- Guests see whether their host PC is on, when it was last on, and the host's email, and can remove a host they no longer use.
- Sessions that run on a guest's own subscription recover more reliably after the host updates or restarts, and explain why a tool was refused.
- When you leave a host, everything that host's sessions left in that browser is cleared.

### Phone (thread0 Remote)
- After a short disconnection, the phone catches up on updates it missed, so a finished turn no longer stays "running".
- The account picker shows the last known limits and models right away.
- Voice input on Android tablets no longer repeats words, keeps listening when you pause, and does not stop when your finger moves slightly.

### Organizations
- The PC sends a registration heartbeat every 15 minutes, so the admin console shows when each PC was last seen.
- One row per PC in the console. A PC released by an admin, removed with its member, or left behind by a deleted organization now actually leaves.
- A member who is removed can no longer read the organization's policies and announcements with an old sign-in.
- Model rules judge the exact model a session will run, and an organization's update address ends with the organization.

### Fixes
- The app no longer freezes for a few seconds every minute while it checks past sessions, and session lists no longer read the disk for every update.
- Deleted sessions no longer keep their conversations in memory.
