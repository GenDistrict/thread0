# thread0 0.1.299

This release lets collaborators move a shared session between their accounts and the host's accounts without losing the conversation, and makes Remote connections steadier on slow networks. It includes all changes since 0.1.290.

## Changes

- A shared session can now switch accounts in every direction: between the host's accounts, from a collaborator's account to a host account, and from one collaborator's account to another. The whole conversation and its tool history move to the new account, so it continues where it left off. The previous account's reasoning is not carried over, and sessions in security mode move with masked text.
- A collaborator can run a session on their own subscription and let everyone in the session use it. The host and other participants send messages in that session one at a time, and each message shows who sent it. Only the collaborator who pays for an account can move a session onto that account.
- When the collaborator whose account runs a session is removed, stops sharing, turns off their PC or their access expires, the session moves to the host's default account automatically and the host is notified. If no host account can take it, the session shows that an account is needed and what to do next.
- Collaborators reconnect about a second after a dropped connection instead of waiting up to a minute, and the first connection to a host PC meets faster.
- If a PC no longer recognizes a phone or browser that connected before, the phone now shows the same confirmation code as the PC and asks you to approve it on the PC, instead of only saying it is reconnecting.
- Long replies and session histories keep arriving on slow mobile networks without the connection dropping or messages being lost.
- When a chat's file list cannot be loaded, the chat no longer inserts an error row at the top or moves the message you were reading; the list retries by itself.
- Remote marks a conversation that could not be brought up to date with the time it was last updated and offers to reload it, instead of showing older messages as current.
- Switching a session between Claude and GPT keeps the full history. Update downloads resume after an interruption instead of starting over. Remote reconnects cleanly when an iPhone returns to the app, and the tray menu follows the app language.
- Cleaning up duplicate devices now only affects your own devices, never collaborators' devices.
- A consent choice made when starting work with your own account stays selected when you change the model or effort.

Update the host PC and every collaborator PC that provides an account to use shared collaborator sessions. Sessions started before this release stay usable by the collaborator who provided the account; to share such work with everyone, start a new session or move it to a host account. Updating Remote alone does not update the software on either PC.
