# thread0 0.1.353 (Windows and macOS)

This release brings Windows and macOS back to the same version. AI sessions can now register the files they make so they appear in Artifacts, Remote inside the desktop app keeps its chat bar on short windows, and invitations you receive show up in the desktop app. For macOS it also includes everything since 0.1.312 (see the [0.1.343 notes](v0.1.343.md): Gemini, Remote in the desktop app, guest conversations, steadier Remote on slow networks).

## Changes

### Artifacts
- Sessions can register the files they produce. Claude and GPT sessions have a register tool, so a document, page or image the AI makes appears in Artifacts and opens on your PC and phone, instead of the AI pointing you to a local web address.
- Files a session creates outside its folder now appear too, when the answer or the session's commands name them and they were created or changed during that session. Existing files elsewhere on your computer are not exposed this way, and credential locations are never registered.

### Remote in the desktop app
- The chat bar stays visible when the window is short. The session list and the conversation scroll on their own, so you can always type and scroll down.
- Guest invitations you receive show a badge on Remote and one line on Home; open Remote to accept or decline.

### macOS
- Dialogs no longer shift when an organization limit or a long account name changes a line on macOS fonts.

## Known limitation
- On a slow receiving device, large transfers to Remote can run at about 75–90% of the link's speed. Pings and replies stay responsive. A fix is planned.
