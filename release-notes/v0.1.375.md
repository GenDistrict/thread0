# thread0 0.1.375

Windows and macOS (Apple Silicon) ship the same version.

Newer Claude Code and GPT engines, stronger personal data protection, one-click diagnostics, and fixes for guests, the phone app and connections.

## Changes

### AI engines
- Claude Code is updated to 2.1.311 and GPT (Codex) to 0.166.0. Your existing sign-ins keep working; there is nothing to sign in again.
- Switching a Claude session to a model with a smaller context window first summarizes the conversation with the current model. thread0 now asks before that switch, so the summary never uses your plan's usage by surprise.
- GPT's experimental memory stays off inside thread0, so what one person says in a shared session is not carried into another session.
- A chat-only Claude session no longer reaches connectors registered on the account.
- Claude session cost no longer grows every turn; each session shows its own cost.
- Connectors and the runtimes thread0 downloads now use a fixed, tested version instead of whatever was newest that day.

### Personal data protection
- No longer marked Beta. An ⓘ next to the setting lists the countries whose number formats it recognizes.
- Recognizes more US, Korean, Canadian and Latin American personal data (social security and tax numbers, addresses, postal codes, bank accounts, health cards), including copied or reformatted text and names in longer documents.
- Values hidden from the AI and restored on your PC are now marked with a dotted underline in the session; hover to see what the AI saw.

### Guests
- A guest can no longer change your rule files (AGENTS.md, CLAUDE.md and similar) or loosen a session's permission mode below what you set. If the AI tries to edit those files during a guest's turn, only you are asked.
- In sessions with guests, the AI and the phone show who sent each message.
- You can choose which sessions a guest joins while you create the invite.

### Phone and Remote
- **Send diagnostics** now sends the report to us in one tap and shows a reference number; you no longer have to save a file and email it.
- If the share sheet refuses a file, Remote downloads it instead; if saving fails, the file is downloaded under its name. A kept copy that can no longer be read says so and offers to get it again from the PC.
- A phone that was already registered no longer gets stuck on "too many requests" after switching PCs a few times.
- Tapping a kept file opens the PC's newer version when the file has changed, and files the AI mentioned in a session can be downloaded from the session.
- Organization PCs follow account-level phone approval like every other PC.

### Mac and Windows
- On Mac, typing Korean and pressing ⌘+Enter no longer leaves the last syllable behind.
- An idle GPT conversation no longer turns red when its engine closes in the background.
- GPT's own log files no longer grow without limit and slow every start.
- Sending many PDF marks shows progress.
