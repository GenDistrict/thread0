# thread0 0.1.290

This release improves connection stability on mobile networks, collaborator access, sign-in recovery and scrolling inside long sessions. It includes all changes since 0.1.286.

## Changes

- Keeps Remote connected while a long session history or a large reply arrives over a slow mobile network. Previously the connection could drop and reconnect in the middle of receiving it.
- Collaborators connect as soon as they open the shared workspace, and the PC no longer keeps reopening an empty collaboration channel while nobody is there.
- A collaborator who accepted an invitation in a second browser can now start work with the inviter's subscription. Before, that browser connected but every run was refused.
- Remembers when you decline a device's connection request, so the same device no longer brings the approval card back each time it retries. On the device, Request connection again sends one new request, and approving it clears the decision.
- Several Remote tabs in the same browser no longer take the connection from each other.
- Claude sign-in can be retried after the sign-in window was closed, without restarting thread0. The signed-in account shows its organization and plan, so a Team or personal plan choice is visible after sign-in. If the browser does not open for GPT sign-in, the sign-in address is shown so you can open it yourself.
- Scrolling up while a reply is still being written now stays where you left it, and scrolling back to the bottom follows new output again. Loading earlier messages keeps the message you were reading in place.
- Commands that finished without reporting a result no longer show as running when the next turn starts.
- Home groups device and collaborator cards under Connections. The remote app card lists only remote apps connected to this PC. Settings are grouped into six searchable categories, and the update check shows download progress.
- Adds Chilean RUT and RUN numbers to local personal-data detection, adds a restored copy for generated files that contain masked values, and stops replacing an unreadable masking key with a new one.
- Keeps the PC awake while a collaborator's work runs with their own account, and shows collaborators which thread0 version the other PC is running.
- Remote on macOS can download restored session files that are stored in system temporary folders.
- Adds a recent connection log to Settings, Diagnostics on Remote and to the desktop diagnostic export, to help investigate connection reports.

Update both participating PCs to use the new connection and collaboration behavior. Updating Remote alone does not update the software on either PC. Automated checks that run a GPT session were not completed for this release because the test account had reached its usage limit; Claude sessions, routines, sign-in, packaged startup on Windows and macOS, and PC-to-Remote connections over a throttled mobile-network profile were checked.
