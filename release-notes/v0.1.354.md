# thread0 0.1.354 (Windows) / 0.1.357 (macOS)

This release makes personal-data masking much stronger for Latin American documents, lets organizations enforce more of their security rules on every member's PC, and makes Remote keep near full speed on slow phones and networks. First run is simpler, routines keep working inside the session you started them from, and a session keeps the model you picked when you come back to it. The macOS build is numbered 0.1.357: it is the same release plus one fix for Gemini sessions on macOS.

## Changes

### Personal-data masking (security mode)
- National IDs from across Latin America are recognized, including Chile RUT, Argentina CUIT, Brazil CNPJ, Colombia NIT, Peru RUC, Uruguay CI, Ecuador cédula, El Salvador DUI, Guatemala DPI/CUI and Venezuela cédula/RIF. Numbers with a check digit are verified before they are masked; numbers without one (such as DNI or passport numbers) are masked when a label says what they are.
- Bank accounts (IBAN, CLABE, CBU) and street addresses in Spanish, Portuguese and English are masked.
- Amounts can be masked too. This is off by default, because the AI cannot calculate with masked amounts.
- Spreadsheets and document tables are read as tables: a column header such as "RUT" or "DNI" now protects every value in that column, including number cells in Excel. Keys in JSON, YAML and .env files count as labels the same way.
- Text copied from PDFs or web pages with unusual characters (non-breaking hyphens, full-width digits, invisible spaces) is masked correctly, and numbers are no longer cut in the middle.
- Fewer false alarms on ordinary text, such as title-case phrases or decimal numbers in data files.
- The key that protects the masking dictionary is now sealed by your operating system (Windows DPAPI, macOS Keychain).

### Prompt-injection check
- Common phrases such as "you are now…" or "admin mode" no longer raise a warning on their own; a quick second check by the AI decides. Clear attempts (ignore previous instructions, hidden instructions, exfiltration) still warn immediately.
- Each session's own AI does the second check: Claude for Claude sessions, GPT for GPT sessions, Gemini for Gemini sessions. It never borrows another account.
- The warning card shows why the text was flagged and quotes it.
- Attachments are checked in every session. Web and connector results are checked in Claude sessions.

### Organizations
- Administrators can require the prompt-injection check and amount masking for all members. Settings show these as "Organization policy".
- Organizations can block reading credential files and cloud metadata outright, with no approval card to click through.
- When an organization requires it, files a guest downloads are masked on every path, including the phone app. Guests can never restore the original values; only the PC owner can.
- On enrolled PCs, commands typed in the terminal panel are recorded in the audit log as metadata only (never the content).
- If an organization policy blocks starting a session from Home, the reason (folder, model or engine) appears next to the chat bar, so you know what to change.
- Gemini is not offered as a pay-as-you-go organization provider. Use the built-in Gemini engine with a personal Google account instead.

### First run and Home
- First run asks one thing: Claude, GPT or Gemini. The "find existing sign-ins on this PC" step is gone.
- Your first message is blocked only by a confirmed problem (offline, signed out, usage limit reached), not while the app is still checking.
- After you sign in, Home shows the normal layout right away: your accounts and limits, Add account, and Remote devices, with tooltips that say what each does.

### Sessions and routines
- A model or effort you change in a session is saved immediately, so it stays when you resume the session.
- New routines continue the most recent session in their folder by default, the way a scheduled task in Claude Code does, instead of starting a new session every run. Choose "new session" if you want one. Routines an AI creates from a conversation run inside that conversation.

### Remote
- Large transfers keep near full speed on slow networks and slow phones. This fixes the known limitation in 0.1.353, where they could run at about 75–90% of the link's speed. Pings and replies stay responsive during big transfers.
- Protection against replayed messages is stronger on long connections.

### macOS
- Gemini sessions no longer fail the next reply after you change effort, model or plan mode. The previous Gemini process could report its own shutdown as an error on macOS.
