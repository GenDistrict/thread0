# thread0 0.1.255

This release makes phone-to-PC connections more likely to go direct, lets the PC and phone report connection quality, scales the relay for many more users, and lets Remote invite collaborators.

- Direct connections prefer the local network first: the PC now advertises its real LAN address and two STUN providers help hole-punching on other networks. When a direct route cannot be established, the encrypted relay still takes over automatically.
- The relay now scales across multiple server instances behind a cross-instance switchboard, so a single busy instance no longer limits everyone. Authenticated requests are no longer subject to the shared per-address limit, so many people behind one network address keep working.
- Remote can invite collaborators for early-access accounts: the invitation form on the phone uses the same email-bound invitation as the PC. Permission changes, extensions and revocation remain PC-only.
- Collaborator direct messages on Remote: the message bar now sits on the screen bottom with the same spacing as session chat.
- Guest sessions are role-honest: observers see read-only cards, collaborator settings only show what applies to them, and every denied action names its reason.
- Remote paints its first screen faster: the sign-in card skeleton appears immediately, the intro card no longer waits for the sign-in handshake, and bundles are served compressed.
- Diagnostics gained content-free connection metrics for the product owner's accounts (transport chosen, upgrades, fallbacks, candidate kinds). No addresses, conversation text or files are included.
- Test boot never hands URLs, files or folders to the operating system; the packaged verification suite runs without opening external programs.
- Electron 43.7.1.

Update the host PC and refresh Remote to use the matching implementation. Automated fixtures and package checks do not replace real-device acceptance; user live validation remains pending.
