# thread0 0.1.268

This release separates personal Claude/GPT subscriptions from organization API management and updates the collaborator workflow for starting work on an owner's PC. User live validation remains pending.

- Folder permissions recognize macOS path aliases and Windows directory junctions that refer to the same allowed folder. Excluded folders and links that escape the allowed folder remain blocked.
- Organizations manage API connections, access and API usage. Personal Claude/GPT sign-ins, session execution and usage remain independent of organization membership, revocation and API budgets. Legacy organization enrollment does not require subscription assignment; organization revocation preserves personal credentials and device connections.
- Active collaborators receive a personal default folder even when no shared folders or sessions have been selected. They can create subfolders inside that workspace and start new work there. Explicitly allowed folders also appear in the folder picker.
- Starting from Home uses the selected/default account and preserves the first message and attachments. Session creation and navigation retain the same session while permissions refresh; delayed or failed sends keep a recoverable outbox entry.
- Switching between Claude and GPT preserves a single selected conversation and its history. Collaborator session lists include shared conversation modes, and delayed discovery responses preserve newer session updates.
- Work using a collaborator's own PC account stays in the owner's logical conversation. Executor backing histories are excluded from the ordinary session list. The executor's actual model and usage now reach the conversation header and survive reopening; an initially empty title is filled from the first message.
- Owners can edit an existing collaborator's account-source policy from Access. The service preserves the policy across invitation refreshes and additional device bindings.
- Group-room access and the conversation picker have been updated. Chat sends show pending/retry states, and attachment chips use one aligned container on phone and desktop widths.
- Long desktop conversations keep transcript layout work separate from typing. The grid and scroll viewport are bounded while retaining the full history and message navigation.
- GPT sign-in keeps a pending browser callback separate from previously saved account state. Retries wait for the old listener to close, and duplicate startup clicks share one attempt. Organization API access is checked only for an explicitly selected API connection.

Update both the work PC and the PC providing the AI account, and refresh Remote. The own-PC account path uses that account's configured default model; in-chat remote model selection and first-connection recovery remain under review. The unstable Wi-Fi report has been investigated but this release does not claim a connection-timing change.

A reported loss of both provider sign-ins after a Mac restart remains under investigation; the additional login-flow changes do not establish a resolution of that separate credential-persistence report.
