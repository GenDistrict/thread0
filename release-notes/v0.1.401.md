# thread0 0.1.401

Windows and macOS (Apple Silicon) both ship as 0.1.401.

Manage connectors and plugins by talking to home, sign in to remote connectors such as Figma outside a session, a start-of-day summary on home, and a smoother Remote on phones.

## Changes

### Connectors and plugins from home
- **Ask home to set up tools.** Home can list each AI account's connectors, plugins and skills, add one connector to several accounts at once, start a connector sign-in, and install, turn on, turn off or remove plugins. Every change asks you on a card first.
- **A session can ask home for a missing tool.** When a task needs a connector or plugin that isn't there, the session asks you on a card and home takes it from there.
- **Apply a new connector to an open session.** After you add a connector or plugin, an open Claude session offers **Apply to this session**: it reopens on the same conversation with the new tool. GPT sessions pick new connectors up on their own.
- **Remote connector sign-in outside a session.** Claude and GPT accounts get a **Sign in** button for remote connectors in Settings → Connectors. Sign in in this PC's browser; if you sign in on your phone, paste the address the browser ends on.
- GPT remote connector sign-in works again (it had stopped working after an update of the GPT runtime).
- New preset: Figma's official connector (Claude and GPT accounts).

### Home
- **Start your day with what you left.** The first time you open home each day, it suggests up to three things you left unfinished — approvals waiting, results to check, work in progress — and a morning phone notification says how many there are.
- Home cards have an **Open** button next to **Reply**.
- A short line on the PC app's home helps you connect your phone, until you do or close it.
- A session started from home keeps the name home gave it.

### Remote (phone and browser)
- After connecting, Remote offers to turn on notifications once. Phones that already get notifications aren't asked.
- On keyboard devices (Mac, PC) Enter sends in the session composer, and Shift+Enter starts a new line; on phones Enter starts a new line.
- Opening Remote in a phone browser first shows how to add it to the home screen, with steps for each browser; on PC browsers it's a small card in the corner.
- Pictures, video and audio in a chat load when you need them instead of all at once, and file transfers move to the faster direct connection while they run.
- Wide HTML results fit the phone screen, and you can zoom with two fingers; comment pins stay on their elements.
- Files opened from a session's file list can be edited and sent back to that session.
- Fewer reconnects: connections are no longer cut about every hour.
- On iPhone home-screen apps, the text cursor no longer lands below the input when the keyboard opens.

### Updates and sign-in
- **Mac updates install on their own** when you quit, or while the app is idle — the same as on Windows.
- Updates that fail because a network inspects HTTPS now retry against a second address with the same files, and explain what to do when they still fail.
- Claude sign-in in the app: after **Open sign-in page**, a large code box takes the place of the waiting line, and a rejected code is named as such.

### Fixes and smaller changes
- Using up a limit and continuing on another account works for sessions that moved into a subfolder.
- Gemini "no capacity" errors read as "the model is busy".
- The Gemini runtime updates to the version this app was tested with.
- On iPhone, the video viewer's comment and shape buttons no longer stay disabled.
