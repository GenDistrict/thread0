# thread0 0.1.361 (Windows and macOS)

This release makes your thread0 account easy to find and sign in to, gives a first run without an AI account somewhere to go, and fixes a phone app that froze every minute. GPT can now connect apps from Settings or from inside a session, and organizations see activity per person and day.

## Changes

### Your thread0 account
- The Settings button in the sidebar shows whether you are signed in. Click the mark to go straight to your account in **Settings → Connections**.
- There is one sign-in window. Home, **Add device**, **Guests** and the Remote tab all open it, so you no longer have to find where sign-in lives.
- The Remote tab inside the PC app signs in and out through that same window.
- If an email is already in use, you can continue with it in one click. Google sign-in that stalls can be reopened or cancelled.

### First run
- You can start without an AI account. **Look around first, without an AI account** opens the normal Home with a banner to connect one later.
- If you were invited as a guest, the first screen points you to **Remote**. The invitation email also says you can join from the PC app's Remote, not only from the phone.

### Phone
- The phone app no longer freezes for a moment every minute.
- Result lists load quickly. Working files load only when you expand or search them.
- The Sessions tab shows "No sessions yet" with **New session** instead of a loading spinner, and shows your sessions immediately when you return to it.
- On iPhone, the close button of a file preview is no longer hidden under the status bar.

### GPT
- Apps can be connected from Settings. When you come back from the connection page, thread0 checks again and shows it as connected. A session can also ask to connect an app and continue once you have.
- Auto mode never approves app connections or plugin installs on its own.
- A GPT turn no longer stays on "Working…" when the session failed to start, and **Stop** works before the turn has started.
- Reference folders work in a GPT conversation before its first message.

### Security mode
- The security mark on each turn shows which checks actually ran. If personal-data protection was off, it says so.
- In PDF tables, ID numbers labelled by a column header are now masked.

### Organizations
- The admin console shows activity per person and per day: sessions, turns, tokens and estimated cost for each AI. It also counts external guest activity. Conversation content, file names and email addresses are never sent.

### Fixes
- Resuming a conversation whose last reply was an error (for example an expired sign-in) now continues with the conversation's real model instead of failing with "There's an issue with the selected model".
