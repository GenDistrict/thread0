# thread0 0.1.371

Windows and macOS (Apple Silicon) ship the same version.

A quick fix for Claude sign-in on some Windows PCs, plus a few display touches.

## Changes

### Claude sign-in
- On some Windows PCs, Claude sign-in stopped within seconds, or the sign-in page never opened. thread0 now finds the Windows system programs it needs even when the PC's settings hide them, so sign-in works on those PCs.
- If the sign-in window cannot open, the first-run card offers **Sign in inside the app** instead of a retry that fails the same way.
- When signing in inside the app takes more than 20 seconds, **Open sign-in page** comes first, so you can finish in your browser.

### Display
- A device that never chose a theme now follows the system setting: light when your computer is light, dark when it is dark. If you chose dark, it stays dark.
- In the light theme, line icons are thinner, and floating panels and menus use a soft warm shadow instead of a dark band.

### macOS
- The local AI runtime on macOS reads its version correctly, so automatic runtime updates work.
