# thread0 0.1.269

This hotfix updates collaborator file access and localized attachment errors. Windows 0.1.269 and Remote are published. macOS remains on 0.1.268 while its 0.1.269 candidate waits for the local build runner.

- Legacy Full-access collaborator records inherit the role's file capabilities only where the old record omitted those fields. Explicit denials and folder boundaries remain enforced.
- Failed attachment uploads show an error in the viewer's selected language. Retrying an upload clears the previous upload error while preserving current validation messages.
- Account-default model labels, including older cached labels, use the selected language. Subscription labels and Home status messages also use localized text.

Update the work PC and refresh Remote to use the corresponding changes. New first-screen layouts, account-readiness and model-discovery recovery, and own-account execution investigations are separate work and are not included in this hotfix.
