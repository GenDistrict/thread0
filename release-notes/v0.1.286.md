# thread0 0.1.286

This release updates collaboration, connection recovery and the desktop and Remote interface.

## Changes

- Adds recovery for expired connection credentials, interrupted output delivery and returning to a collaborator workspace after refreshing Remote.
- Separates a restored connection from a confirmed running task, so an old saved task does not become recent activity merely because its connection reopens.
- Improves own-account attachments, shared-session history and account discovery, with clearer localized recovery guidance.
- Shows downloaded size, total size and percentage while preparing a desktop update, followed by a separate verification step.
- Simplifies Home by removing summary statistics and recent-session cards. Desktop and Remote use the same People label; session files remain accessible without a separate Library menu.
- Removes the extra switching arrow and reduces spacing between Remote model, effort and send controls.
- Updates language guidance to follow the current prompt's language, with English as the fallback when the language is unclear.

Update both participating PCs to use the new desktop collaboration and recovery behavior. Updating Remote alone does not update the software on either PC. Physical-device validation of connection recovery is ongoing; this release does not claim that every reported connection incident has been conclusively resolved.
